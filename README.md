# 같이 보는 방

친구들과 방에 둘러앉아, 가운데 노트북으로 진짜 유튜브를 보는 게임입니다.

- 노트북 화면에 실제 유튜브 사이트가 열려서 검색·추천·로그인을 그대로 쓸 수 있어요.
- 친구들(보리·모찌·두부)이 영상을 보며 웃고, 놀라고, 말을 걸어요.
- 리액션 버튼과 채팅으로 반응하면 분위기 게이지가 올라가고, 가득 차면 파티가 열려요.
- 유튜브 전체화면은 노트북 화면 안에서만 커져요.

## 실행 (Windows)

1. [Node.js](https://nodejs.org)를 설치합니다.
2. 이 저장소를 내려받아 압축을 풉니다.
3. `start.bat`을 더블클릭합니다. 처음 한 번은 필요한 파일을 설치하느라 시간이 걸려요.

`start-web.bat`은 브라우저로 여는 버전입니다. 이 버전에서는 노트북에 유튜브 링크를 붙여넣어 재생해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 방, 캐릭터, 노트북 등 게임 화면 |
| `main.js` | 앱 창, 노트북 속 유튜브, 로그인 유지, 전체화면 처리 |
| `server.js` | 브라우저 버전용 작은 서버 |
| `icons/` | 앱 아이콘 |
