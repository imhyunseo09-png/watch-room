# 같이 보는 방

친구들과 3D 방에 둘러앉아, 가운데 노트북으로 진짜 유튜브를 보는 게임입니다. 친구(SHORELINE 탐험가, 펭귄 횡단 펭귄)를 클릭하면 세계의 그림체가 그 친구의 게임으로 바뀝니다.

- 노트북 화면에 실제 유튜브 사이트가 열려서 검색·추천·로그인을 그대로 쓸 수 있어요.
- 마우스를 노트북 화면에 올리면 화면 속 커서가 되고, 타자를 치면 3D 키보드의 같은 키가 눌려요.
- 친구를 다시 클릭하면 그 게임의 동작·목소리·상호작용이 이어져요.
- 유튜브 전체화면은 노트북 화면 안에서만 커져요.

## 실행 (Windows)

1. [Node.js](https://nodejs.org)를 설치합니다.
2. 이 저장소를 내려받아 압축을 풉니다.
3. `make-shortcut.bat`을 더블클릭하면 바탕화면에 **같이 보는 방** 아이콘이 생깁니다. 처음 한 번은 필요한 파일을 설치하느라 시간이 걸려요.
4. 그 아이콘(또는 `start.bat`)으로 실행합니다.

`start-web.bat`은 브라우저로 여는 버전입니다. 이 버전에서는 노트북에 유튜브 링크를 붙여넣어 재생해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `src/app.js` | 3D 방, 노트북, 화면 속 마우스·키보드 |
| `src/characters/`, `src/themes/` | 두 친구의 캐릭터와 그림체 |
| `classic.html` | 예전 2D 화면 (브라우저 버전) |
| `main.js` | 앱 창, 노트북 속 유튜브, 로그인 유지, 전체화면 처리 |
| `server.js` | 브라우저 버전용 작은 서버 |
| `icons/` | 앱 아이콘 |
